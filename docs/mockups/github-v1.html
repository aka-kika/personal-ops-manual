Where the data comes from

What you seeSource (read only)
Repo list, private or public, latest tag, open PRs, last buildThe gh login that already exists on this Mac (gh repo list, gh release list, gh pr list, gh run list). The app gets no new token.
Branch, uncommitted, unpushed, behindLocal git in the folder named by the page's path: git status --porcelain and git rev-list --count. No network needed.
Installed app versionSame check as Drift: the app's Info.plist in /Applications.

If a token is ever needed (for example if gh is signed out): it lives in the macOS Keychain only. Never in a page, never in a file. Until then, no token at all.

Note on today's data: gh repo list aka-kika says all 30 repos are Private right now, including personal-ops-manual, which its page calls public since 2026-09-15. The Public group above is sample data. Real visibility will always come from GitHub, not from the page, so a page can never lie about it.

What updates by itself

  • Automatic: only the numbers on screen (state, tags, PRs, builds). They refresh, nothing is written anywhere.
  • Pages: never edited by the app. A difference becomes a proposal (the "Suggested page update" card). You press Send to operator, it adds one line to _inbox/reports.md, and the operator edits the page later. The same flow as Report in Drift.
  • Proposals shown: latest release differs, visibility differs, repo renamed or gone, local path missing.

How a page names its repo

Two new lines in the page's frontmatter, next to the approved checks: list. Pages without them just show GitHub data from the title, or nothing.

repo: aka-kika/personal-ops-manual
path: ~/_KIKA_MAIN/_INFRA/apps/ops-manual
checks:
  - app "Personal Ops Manual" 2.2.5 notarized
  - port 4319 node

repo is the GitHub name. path is the folder on this Mac (optional: a repo with no local copy shows only GitHub facts). The page title becomes just the repo or app name: "Personal Ops Manual", not "Personal Ops Manual (release)". The release tag stays on the page, so nothing is lost and you can still filter by it.

How often it refreshes

  • Same interval setting as Drift: once a day by default (03:20 in the samples), plus the Refresh button.
  • Opening a repo does not trigger network calls by itself; it shows the last refresh and its time.
  • If gh is signed out or offline, local git state still shows and the GitHub lines turn grey with "couldn't check".
