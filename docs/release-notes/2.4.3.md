Notarized Developer ID build. Unzip and drop into /Applications. macOS 26 or newer.

New in 2.4.3
- **App Store status in the category overview:** each app's state in App Store Connect (on sale, waiting for review, in review, pending release, rejected) with how long, the version and the price, read with `asc status` when the pane opens and again with Cmd-R. Peach only for a rejection or a wait for review longer than 14 days. When App Store Connect can't be read, the pane says so.
- **Every category says what lives there:** Agents, APIs, Maintenance, Recovery and Skills have an overview page now, and App Store and CLI tools use their index page.
- **The Inbox file as a page:** with Inbox picked and no line picked, the right side shows `_inbox/reports.md` itself, read only.

Fixes in 2.4.3
- **No "Last build" row for a repo without GitHub Actions.** Repos with builds still show the green check, the workflow and the date.
- **Fewer icons:** the folder icon above the Inbox list is gone (right-click Inbox in the sidebar for Open in Finder), and so is the page icon in an Inbox line's corner (the "Open" button below does the same).
