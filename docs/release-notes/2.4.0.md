Notarized Developer ID build. Unzip and drop into /Applications. macOS 26 or newer.

New in 2.4.0
- **GitHub, calmer:** repos grouped Private then Public, a lock or globe per repo, names without "(release)", and one small dot when something is not saved yet. The numbers are on the repo's own page.
- **Repo page:** branch, uncommitted files (only files git already tracks), unpushed and behind, latest tag against the installed app, open pull requests, the last build (a green check when it passed) and the folder on this Mac. Only rows that need attention get a mark.
- **GitHub overview:** pick GitHub with no repo and see how many repos have work not saved, plus the rules from the GitHub index page. Right-click GitHub in the sidebar: Refresh, Copy Path, Open on GitHub.
- **Out of date goes to the Inbox by itself:** what no longer matches (a page's latest release, a missing repo folder, any checks: line) is written once into the inbox, under "Out of date: GitHub" and "Out of date: this Mac", before the readers' reports. A fact that holds again leaves by itself. No buttons.
- **opsmanual check:** the same check without opening the app, for the operator's run and the weekly maintenance (the app with --check, or scripts/opsmanual).
- **MCP in one row:** your servers and third-party ones in one list, yours marked.
- **Right-click a page:** Open Repo or Open Site when the page has one, then Open in Default App, Copy Path, Refresh.

Changes in 2.4.0
- **The app only reads:** no editing, no new page, no trash. Pages change through the operator.
- **Sidebar:** no search or gear buttons. Search is Cmd-K, Settings is in the app menu.
- **Drift** counts repos with work not saved (pages with a path: line) and shows GitHub mismatches too.
